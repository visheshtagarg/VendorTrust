# Fixes applied

Every item from both code reviews, where it was fixed, and the test that proves it.
Tests: `python -m pytest -q`.

## Critical

| # | Issue | Fix | Test |
|---|---|---|---|
| 1 | Approval possible without the bank account being read from a document | New `ACCOUNT_RE` accepts no separator, spaces in the number, `A/C No.`, next-line values, then requires 9–18 digits. `FIELD_NOT_FOUND_BANK_ACCOUNT`/`_IFSC` are High and unresolvable. Any unresolved Missing / Not Found / Invalid / Needs Manual Review / Mismatch finding blocks approval regardless of severity (`services/submission.py:approval_blockers`). | `test_account_number_variants_are_extracted`, `test_account_not_found_blocks_approval_and_cannot_be_resolved`, `test_any_unresolved_missing_or_invalid_status_blocks_even_if_medium_or_low` |
| 2 | Document type never checked; sha256 unused; fields pooled | `DOC_TYPE_CONTENT_MISMATCH` checks each slot for its key fields and flags a GSTIN in the PAN slot. Same file in two slots is refused before saving. `documents.sha256` stored and indexed; reuse by another PAN → `DOCUMENT_REUSED_ACROSS_VENDORS`. Bank fields are trusted only from the Bank Proof, GSTIN/legal name only from the GST certificate (`FIELD_SOURCES`). | `test_gst_pdf_in_every_slot_is_rejected_before_saving`, `test_wrong_document_in_slot_is_unresolvable_mismatch`, `test_bank_account_only_trusted_from_bank_proof`, `test_sha256_is_stored_and_reuse_across_vendors_is_flagged` |
| 3 | Findings that can never be legitimate were resolvable | `UNRESOLVABLE_RULES` set in `core/engine.py`, enforced in `resolve_finding`, `approval_blockers` and the UI. | `test_unresolvable_set_contains_reviewed_rules`, `test_resolving_gstin_pan_link_is_refused` |
| 4 | Engine never recommended rejection | `recommend()` returns Recommend Reject / Needs Documents / Pending Review / Approve-ready with reasons, mapped to Rejected / Pending / Approved. Stored on the submission, shown live in the Review Center, and recorded with the human decision (`agrees_with_engine`). | `test_recommendation_outcomes_map_to_problem_statement` |
